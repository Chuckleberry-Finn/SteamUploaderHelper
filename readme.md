## Setup:
**Place the exe (or build your own exe, or run the python `py/app.py`) with a copy of [SteamUploader (C++)](https://github.com/SimKDT/Steam-Uploader) alongside it, and simply Run.**<br>
<sup>Example Folder Contents: `PZ SteamUploader Helper.exe`, `SteamUploader/`  or  `py/`, `SteamUploader/`</sup>

#### Select the gear and populate the `workshop folder` and `steamUploader.exe` paths.

- Batch Regex
- Batch upload in full
